Privacy Policy

Last updated: October 21, 2026

About the application

ANNA Personal Backup is a private application intended for use by its owner to create and restore encrypted backups using Google Drive.

Google account access

The application requests Google Drive file access through Google OAuth 2.0. Its intended access is limited to files authorized for use with the application.

Data handling

Backup contents are intended to be encrypted locally before upload. Google Drive stores the resulting encrypted backup files. OAuth credentials are used to maintain authorized access.

Data sharing

The application is not intended to sell personal data or share Google user data with advertisers. Data is processed by Google Drive as the selected storage provider.

Retention and deletion

Backup files are retained according to the owner's backup retention settings and can be deleted by the owner. Access may be revoked through Google Account security settings.

Contact

For privacy inquiries, contact the application owner using the support email shown on the Google OAuth consent screen.
